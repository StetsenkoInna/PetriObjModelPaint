# PetriObjModelPaint 2.5.0

Exchange a training ZIP between authors and reviewers, inspect saved networks on a live read-only canvas, and retain simulation trajectories for training data.

## Changes

- Open training ZIPs through File > Open, the Review menu or drag-and-drop. Every review preserves earlier network versions, images, coordinates and session history in the next archive.
- Add findings directly on the live network. Inspect the usual parameter forms without editing the saved model, browse nested objects, and compare versions in independent maximizable windows.
- Reuse the simulation controls and statistics monitor in review mode. Runs and resets operate on an isolated copy of the reviewed version.
- Automatically simulate fresh copies before saving at configurable horizons, initially 100, 1000 and 10000. Disabling automatic runs requires a reason. Preserve failed attempts and execution limits.
- Record sampled place markings and active transition channels, initial/final statistics, errors and source model hashes. Sampling defaults to one unit of model time; larger effective intervals are declared explicitly when data limits apply. Successful execution does not certify task correctness.
- Export the complete expanded network and separate images of nested networks, or choose individual objects and selected elements. Include parameter tables and matching geometry.
- Save a persistent contributor nickname, organization, study group and optional contacts. Missing nicknames receive a reusable two-word name.
- Keep technical identifiers out of the human review form, organize training export under AI, and fix the collapsed results sidebar retaining excess width.
- Bundle shared modeling and review guidance from petri-modeling-skills 0.4.0, verified against its pinned SHA-256.

## Building on 2.4.0

The previous release introduced local desktop MCP with optional token authentication, network image and training ZIP exports, shared modeling guidance, reusable Java libraries and a standalone server. This release extends those features with an iterative review workflow and recorded temporal behavior.

## Installation

Download the archive for your operating system, extract it and run its launcher. Java 23 or newer is required. The simulation libraries remain available separately with source JARs, POMs and the anonymous Maven repository; the server is also distributed as an executable JAR.
