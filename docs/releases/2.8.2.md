# 2.8.2

A patch release: report bugs, ideas and feedback from the Help menu, a cleaner
Statistics panel, and a Statistic monitor without the unused eraser.

## Feedback through GitHub

- **Help** gains **Report a bug (GitHub)...**, **Suggest an improvement (GitHub)...**
  and **Send feedback (GitHub)...**. Each opens the matching issue form in the
  browser, with the module, application version, Java runtime and operating system
  already filled in, so a report needs no copying from **Help > About**.
- The issue is filed under your own GitHub account; nothing is sent from the
  application itself. If the desktop cannot open a browser, the link is shown for
  copying instead.
- The repository has a new **Feedback** form for anything that is neither a bug nor
  an idea, and the bug form gained an optional version field.

## Statistics

- **Open full log** now sits inside the same border as the statistics text, so it
  reads as part of Statistics and no longer as part of **Events protokol**.
- The Statistic monitor no longer has its unused eraser toggle.

## Libraries

Only the desktop editor changed. `petri-math`, `petri-api`, `petri-model` and
`petri-server` keep their current versions.
