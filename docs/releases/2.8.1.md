# 2.8.1

A patch release: one-shot line tools in the Statistic monitor, simulation
evidence in training exports, and a canvas centering fix.

## Statistic monitor

- The vertical and horizontal line tools now place one line per activation. After
  a click the tool switches itself off and its toolbar button is released, so later
  clicks no longer add a second, third or fourth line. Press the button again to
  place another one.

## Training export

- **AI > Export training data** runs the same automatic simulation attempts as a
  review export (horizons 100, 1000 and 10000, on the exact exported PNML) and records
  them in `verification.json` under `simulation`. Observed execution is evidence only:
  the status stays `unknown`. A review export keeps its runs in the review record, so
  nothing runs twice. A model without places gets no attempts and a missing-data note.
- The export dialog no longer offers the main-window screenshot checkbox. The overview
  and every object image, with parameter tables, are always included. The MCP tool
  `export_training_data` still accepts `include_screenshot` for agents.

## Canvas

- A new canvas is centered correctly on every platform, and the Swing tests that
  depend on it are stable on macOS.

## Libraries

`petri-api` is released as 2.8.1 because `ChartConfigDto` gained `releaseLineTools()`.
`petri-math`, `petri-model` and `petri-server` keep their current versions.

See [Training bundles, reviews and image export](../training-data-export.md) for the
bundle contents.
