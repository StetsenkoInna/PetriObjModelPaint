# PetriObjModelPaint 2.6.0

Tell shared places apart from informational arcs at a glance, learn what each connection does by hovering over it, and recognize the app by its own icon.

## Changes

- Draw the link between shared places as a solid double line with an open arrowhead at the copy, pointing from the source: the copy's marking follows from events in the source (In := Out). It replaces the dash-dot line that was easy to mistake for a dashed informational arc.
- Fill both places of a link with a clearly visible grey, showing that their marking depends on events in another Petri-object.
- Hover over an arc or a shared place link to see what kind of connection it is and, in one line, what it does: input, output and informational arcs and the shared place link. Hints also work while a model is animated.
- Show the app's own icon, a place with a token, an arc and a transition, on every window, the taskbar and the macOS Dock instead of the default Java icon.
- Set the release version everywhere it is written, including the PNML tool version and download links, with one script, and test every pull request on CI.

## Building on 2.5.0

The previous release introduced the iterative review workflow with training ZIPs, live read-only review canvases and recorded simulation trajectories. This release makes composed models easier to read, especially for students meeting the Petri-object notation for the first time.

## Installation

Download the archive for your operating system, extract it and run its launcher. Java 23 or newer is required. The simulation libraries remain available separately with source JARs, POMs and the anonymous Maven repository; the server is also distributed as an executable JAR.
