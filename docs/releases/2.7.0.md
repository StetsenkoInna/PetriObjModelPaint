# 2.7.0

The desktop application can install updates from GitHub without replacing files manually.

- One background check when the application opens, with no periodic polling.
- Install, remind tomorrow, skip this build and disable startup checks in Preferences.
- Verified platform archives, including detection of rebuilt releases under the same tag.
- Save the current model before restarting, then reopen it after installation.
- External installer with a previous-version backup and rollback on failure.

2.7.0 must be installed once from its archive because earlier versions have no updater.
The math, API, model and server libraries retain their existing versions.

See [Desktop updates](../desktop-updates.md) for behavior and installation requirements.
