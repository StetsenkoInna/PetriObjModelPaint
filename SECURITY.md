# Security Policy

## Supported Versions

Only the latest [release](https://github.com/StetsenkoInna/PetriObjModelPaint/releases/latest)
receives security fixes. There is no long-term support branch.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead,
email <inna.stetsenko-fiot@edu.kpi.ua> and <sergey24rybak@gmail.com> with:

- A description of the vulnerability and its potential impact
- Steps to reproduce (a minimal PNML file or code snippet, if applicable)
- The module affected (`petri-math`, `petri-api`, `petri-model`,
  `petri-swing-ui`, or `petri-server`)

We'll acknowledge your report and let you know whether it's accepted as a
valid issue. Once a fix is available, we'll coordinate on disclosure timing
with you before any public write-up.
